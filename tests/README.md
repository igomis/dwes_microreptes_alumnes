# Tests

Este README és una guia de carpeta. No cal modificar-lo per entregar un microrepte.

Guarda ací proves automàtiques o instruccions específiques de verificació del projecte.

Quan un test siga específic d'un microrepte, usa el nom del repte en el fitxer:

```text
tests/r2m3.test.php
tests/r2m7-flux.sh
tests/r3m5.test.js
```

Un test ha de comprovar comportament observable: una funció, una classe, una ruta, una validació, una consulta, una resposta HTTP o un flux mínim. No compta com a test un fitxer que només descriu què faries sense executar res.

Si el microrepte té proves, explica en el `README.md` de l'arrel:

- l'ordre exacta per executar-les;
- què comproven;
- quin resultat s'espera;
- si hi ha algun requisit previ, com instal·lar dependències o arrancar el servidor.
