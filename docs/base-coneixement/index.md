# Base de coneixement personal

Guarda ací notes breus i reutilitzables sobre conceptes que hages comprés a
partir dels apunts, la pràctica o les teues consultes d’IA.

- Crea un fitxer per tema, per exemple `sessions.md`, `validacio.md` o `apis.md`.
- Escriu les explicacions amb les teues paraules.
- Enllaça, quan corresponga, l’entrada d’origen de `../ai-log.md`.
- Usa exemples menuts diferents de la solució avaluable.
- No copies converses, respostes completes ni fragments grans de codi.
- Revisa i amplia una nota existent abans de crear-ne una de duplicada.

La base de coneixement és opcional i no substituïx el registre d’ús d’IA ni les
evidències exigides en cada microrepte.
