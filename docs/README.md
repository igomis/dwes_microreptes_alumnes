# Documentació

Guarda ací la documentació de cada microrepte: fitxes, decisions tècniques, notes de verificació o registres de treball.

Usa noms que permeten trobar ràpidament el treball, per exemple:

```text
r2m3.md
r3m5.md
ai-log.md
```

El `README.md` principal ha d'indicar quin és el microrepte actual i quins documents cal revisar.
